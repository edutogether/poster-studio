# Poster Studio — 각자 테스팅 확인표 (행사 전, 노트북마다 한 번)

> 2026-10-23. 모여서 하는 리허설 대신 노트북을 맡는 분이 각자 해 봅니다. **11월 12일(수)까지** 아래 표를 채워 기술 담당에게 보내 주세요.

**준비**: 행사 노트북 · 충전기 · 그 노트북에 붙일 와이파이(대여 와이파이 또는 핫스팟) · 포토프린터와 4×6 인화지 · 충전기

## 차례대로 해 보기

1. **주소 열기** — 크롬으로 **poster.edutogether.kr**을 엽니다. 첫 화면(극장 사진)이 뜨면 됩니다.
2. **와이파이** — 행사 때 쓸 와이파이(또는 핫스팟)에 붙인 채로 합니다. 어느 와이파이였는지 적습니다.
3. **카메라 허용** — «주인공이 될 순간 보러 가기» → 촬영 화면 칸 안 **«카메라 켜기»** → 크롬이 묻는 창에서 **허용**. 내 얼굴이 보이면 됩니다.
   - 묻지 않고 막혔으면: 주소창 왼쪽 자물쇠 → 카메라 → **허용** → 새로고침.
4. **실제 생성 1건** — **«3초 뒤 사진 찍기»** → 찍힌 사진 확인 → **«이 사진으로 포스터 만들기»** → 1분쯤 뒤 포스터 8가지가 나오면 됩니다.
   - 한 노트북에 **1건만** 합니다(1건 약 $0.04). 찍기 전 «샘플 포스터 보기»는 사진 없이 샘플을 구경하는 단추라 생성 시험이 아닙니다.
5. **프린터 4×6 인쇄** — 포스터 하나를 고르고 **«이 포스터로 출력하기»** → 크롬 인쇄 창에서
   프린터 선택 · 용지 **4×6(10×15cm)** · 여백 **없음** · 배율 **기본(100%)** · **머리글과 바닥글 끄기** → 인쇄.
   - **1장이 다 나올 때까지 걸린 시간**을 잽니다. 3분이 넘으면 꼭 적어 주세요(프린터 3대로 하루 인원을 못 따라갈 수 있습니다).
   - 인쇄 창 설정이 위와 다르게 맞아야 잘 나왔다면 그 설정을 그대로 적어 주세요(설명서에 반영합니다).
6. **끝** — 브라우저 탭을 닫습니다. «PNG 저장»은 누르지 않습니다(누르면 사진 파일이 노트북에 남습니다).

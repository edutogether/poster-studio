# Windows 설치판(`PosterStudio-Setup.exe`) · 웹 첫 화면 «↓ 다운로드» 단추 · 현장 PDF 2종

팀장 전달 Bumm님 지시(2026-10-27)라 지시 자체가 승인이다 — `accepted`를 거쳐 바로 진행한다.
기준: Hosting `836b1b9`(태그 `poster-studio-freeze-20261026-audited-100`), 함수 `81a07b4`. 작업 가지 `desktop-20261027`(836b1b9에서).

## 문제

- 행사장 인터넷이나 OpenAI가 멈추면 지금은 포스터를 하나도 못 만든다. 2026-10-16에 «AI 없이 계속하기»(빈 그라데이션 인쇄)를 없앤 뒤로는 비상 경로가 없다.
- 노트북에 설치해 둘 비상판이 필요하다. 주소만 띄우는 바로가기로는 인터넷이 끊긴 순간 같이 멈춘다.
- 그 설치 파일을 받을 자리(웹 첫 화면 단추)와, 현장 진행요원 · 교사 · 아이들이 읽을 안내물이 아직 없다.

## 원하는 결과

1. **설치판**: `PosterStudio-Setup.exe`를 더블클릭하면 Windows 10·11에 설치된다.
   - «나만 / 모든 사용자»를 고르고 위치를 바꿀 수 있다(10/27 Bumm님 기준 정정, 팀장 전달 — 처음 «관리자 권한 없이 사용자별로만»에서 바뀜).
     모든 사용자 `C:\Program Files\InKY Film Festival\Poster Studio`, 나만 `%LOCALAPPDATA%\Programs\InKY Film Festival\Poster Studio`.
   - 바탕화면 `Poster Studio`, 시작 메뉴 `InKY Film Festival` 폴더에 `Poster Studio` · `Uninstall Poster Studio`. 설치가 끝나면 바로 실행된다.
   - «설정 › 앱 › 설치된 앱»과 시작 메뉴 두 방법으로 지워지고, 바로가기 · 폴더가 남지 않는다.
   - 인터넷이 없어도 다음 흐름이 끝까지 된다: 사진 찍기 또는 불러오기 → 포스터 8종 조판 → PC에 저장 → 인쇄 미리보기 → 인쇄.
2. **다운로드 단추**: 웹 첫 화면 «개인정보처리방침» 바로 옆에 «↓ 다운로드»가 생긴다.
   - 누르면 작은 메뉴에 «Poster Studio 설치» 하나가 나온다(Voice Cinema는 완성 전이라 설치판을 만들지 않는다 — 10/27 정정).
   - 누르기 전에는 설치 파일 요청이 0건이다. 배포하지 않는다.
3. **현장 PDF 2종**: `InKY_진행요원_교사용_매뉴얼.pdf`(A4 4쪽 이내), `InKY_아이들용_양면안내.pdf`(A4 정확히 2쪽).
   - Poster Studio만 다룬다(Bumm님 A안 — Voice Cinema는 소개 한 줄도 넣지 않는다).
   - 매뉴얼의 설치 설명은 현장 교사가 따라 할 만큼만 쓴다: 더블클릭 → SmartScreen 넘기기 → 실행 → 바탕화면 아이콘.

## 정한 것(근거)

- **Electron을 쓴다(Tauri 아님).**
  - Electron은 웹과 같은 크로뮴을 통째로 싣고 간다. 그래서 검증을 마친 화면 · 글꼴 · 카메라 · 캔버스 조판이 그대로 돈다.
  - Tauri는 PC마다 판이 다른 WebView2 위에서 돈다. 빌드에는 Rust와 MSVC 빌드 도구(관리자 설치)가 필요한데, 이 PC에는 없다.
  - 판: electron 44.7.0(2026-10-07), electron-builder 26.17.0(2026-09-26). 둘 다 2주 넘게 지난 판이다.
- **설치판에는 AI 생성이 없다(로컬 합성만).**
  - AI를 부르려면 부스 토큰을 설치판에 넣어야 한다. 지시가 «키 · 토큰을 설치판에 넣지 않는다»다.
  - 서버의 허용 출처 목록에 설치판 출처를 더해야 하는데, 서버 함수는 바꾸지 않는다.
  - 그래서 설치판 빌드에서는 토큰 값을 비우고, 서버 확인 · 생성 요청 코드를 타지 않는다.
  - 화면 정책(CSP)도 `connect-src 'self'`로 바깥 요청을 막는다. 앱도 http · https 요청을 전부 끊는다.
- **로컬 합성**: 찍거나 불러온 사진을 그대로 8종 틀에 넣는다(`buildPosters`를 그대로 쓴다). 틀 · 글꼴 · 로고 · 인쇄 규격은 웹과 같다.
  - 설치판 화면에는 머리글에 «설치판 · AI 없이 사진 그대로»를 늘 띄운다. 웹의 AI 포스터와 헷갈리지 않게 하려는 것이다.
- **설치판에는 «샘플 포스터 보기»를 두지 않는다.**
  - 샘플 흐름은 로딩 화면에 «AI가 당신의 영화를 그리고 있어요»를 띄운다. AI가 없는 설치판에서는 거짓 표시가 된다.
  - 그래서 로딩 영상 12편도 설치판에는 싣지 않는다. 웹의 영상 · 로딩 화면은 그대로다.
- **설치판에만 있는 것**:
  - 2단계 «사진 불러오기»
  - 3단계 «PC에 저장»(저장 위치를 묻는 창이 뜬다)
  - 3단계 «인쇄 미리보기»(4×6 인화지에 놓인 모습을 보고 «인쇄하기»를 누르면 Windows 인쇄 창이 뜬다)
  - 웹 빌드에서는 이 갈래가 통째로 빠진다. 웹 번들은 다운로드 단추 말고는 바뀌지 않아야 한다(바이트 대조로 확인).
- **다운로드 단추는 웹의 1단계(첫 화면)에만 둔다.** 설치판에서는 숨긴다.
  - 단순 링크라 누르기 전에는 아무것도 받지 않는다. prefetch · preload · 서비스워커는 쓰지 않는다.
- **아이콘**: `_shared/favicons/inky-camera-512.png`(노란 InKY 로고 원본)를 그대로 쓰고 오른쪽 아래에 «PS» 표시만 얹는다.
  - 표시는 검은 둥근 사각 · 흰 글자, Voice Cinema 시안과 모양 · 위치 · 비율이 같고 크기는 더 작다(Bumm님 «너무 커서 화질 떨어지는 게 보인다»).
  - 크기마다 따로 그리고 작은 크기는 점 글자로 그린다. 글자는 앱 아이콘에만 두고 설치기 화면에는 넣지 않는다.

## 영향받는 사용자·시스템

- **웹**: 첫 화면에 단추 하나가 생긴다. 배포하지 않으므로 지금 라이브 사용자에게는 변화가 없다.
- **설치판 사용자**: 행사장 진행요원이 노트북에 미리 설치한다. 저장소에는 `desktop/`(Electron 껍데기)과 `src/`의 설치판 갈래가 더해진다.
- **서버 함수 · AI 지시문 · Firestore**: 바꾸지 않는다.
- **Voice Cinema**: 이번 작업에 넣지 않는다(10/27 정정). 그 저장소는 건드리지 않는다.

## 제약

- 프로덕션 배포 · GitHub 푸시 · `gh` · master 변경은 하지 않는다. 유료 AI 생성 0건, 라이브에서 «생성»을 누르지 않는다.
- 서버 함수 · 16칸 지시문 · 승인된 UI · 8종 디자인 · 개인정보처리방침 문구를 바꾸지 않는다.
- 기존 백업 · 동결 태그 · `poster-studio-운영자-전달-20261026` PDF를 지우거나 덮어쓰지 않는다.
- 설치판에 키 · 토큰을 넣지 않는다. 코드 서명 인증서는 사지 않는다(SmartScreen 경고는 제약으로 보고).
- 설치 파일(100MB 넘음)은 저장소에 넣지 않는다. GitHub 파일 한도가 100MB다.

## 올릴 자리(제안 — 업로드 · 배포는 별도 승인)

- Hosting(`dist/`)에 넣으면 다음 CI 배포가 그 파일을 지운다. CI는 저장소에서 `dist/`를 새로 만들고, 설치 파일은 저장소에 없기 때문이다.
- 그래서 제안하는 자리:
  - 파일은 Cloud Storage(`inky-poster-studio` 프로젝트)의 공개 객체 하나에 둔다.
  - 주소는 `firebase.json` 리디렉션으로 `https://poster.edutogether.kr/download/PosterStudio-Setup.exe`에 고정한다.
- 단추의 주소는 이 제안을 따른다(`src/downloads.ts`).

## 추가 수정 4 — 설치 · 제거 화면 안내문을 문장마다 줄바꿈(10/28 Bumm님, 팀장 전달 — 지시 자체가 승인)

- **문제**: «설치 위치 선택» 안내문 세 문장이 한 덩어리로 흘러 «시 / 작하시려면»처럼 낱말 중간에서 끊긴다. «Poster Studio(을)를»은 NSIS 기본 문구다.
  한국어 Windows에서 이 칸 글꼴은 굴림 9pt(-12px)이고, 둘째 · 셋째 문장을 이은 줄이 724px인데 칸은 525px다(확인 도구가 설치 창의 글꼴을 읽어 잼).
- **원하는 결과**: 설치 · 제거 프로그램의 모든 화면 안내문이 ① 문장마다 새 줄에서 시작하고(한 줄에 두 문장 없음) ② 줄이 칸 안에 들어가 낱말 중간에서 끊기지 않으며
  ③ «(을)를» · «이(가)» 같은 조사 표기가 없다. 칸보다 긴 한 문장은 문구를 그대로 두고 낱말 사이에서 두 줄로 나눈다(문구를 줄이는 것은 Bumm님 결정).
- **고칠 화면**(10/28 e58b65c 실측 · 칸 폭 실측):
  - 설치 위치 선택: 머리 «…(을)를 설치할 폴더를…», 안내 세 문장.
  - 설치 옵션 선택: 위 안내 한 문장(620px > 525px, «것 / 인지»로 끊김), 아래 안내 «이미 머신별로 설치되어 있습니다.(경로)»(495px > 490px, 경로 중간에서 끊김) ·
    «모든 사용자를 위해 새로 설치. (관리자 …)»(한 줄에 두 마디).
  - 설치 중 · 제거 중 머리 «…(을)를 설치 · 제거하는 동안…».
  - 제거 시작: «…Poster Studio(을)를 제거할 / 것입니다.» · «…주시기 바 / 랍니다.».
  - 제거 옵션 선택(«모든 사용자» · «나만» 설치가 함께 있을 때만 뜸): 번역문에 «\n»이 글자 그대로 찍히고 두 문장이 이어진다. 아래 안내의 경로도 위와 같다.
  - 앱이 켜져 있을 때 뜨는 알림: «Poster Studio이(가) 실행 중입니다. … OK을 클릭하면» — 한국어 Windows의 단추는 «확인»이다.
- **방법**: 문구는 electron-builder가 열어 둔 `customHeader` 자리(언어 문구가 다 정해진 뒤)에서 같은 이름으로 다시 정한다. 같은 이름을 두 번 정하면 NSIS가
  «자리 낭비» 경고(6030)를 내고 빌드가 경고를 오류로 다루므로, 그 몇 줄에서만 그 경고를 끈다(시험 스크립트로 나중 값이 이기는 것을 확인함).
  위치 화면 안내는 MUI 정식 설정 `MUI_DIRECTORYPAGE_TEXT_TOP`으로 바꾼다. 설치 · 제거 흐름과 진행 문장(B안)은 그대로다.
- **확인**: 확인 도구가 화면마다 글 칸의 실제 글꼴로 줄 폭을 재고, 한 줄 두 문장 · 조사 표기 · «\n» 글자를 찾는다. e58b65c에서 실패하는 것을 먼저 본다.
  앱을 켜 둔 채 설치 · 제거를 시작해 알림을 찍고 «취소»로 닫는 시험과, 두 범위가 함께 깔린 PC 시험(제거 옵션 화면)을 더한다.
  설치(나만 · 모든 사용자 새로 · 덮어쓰기) · 제거(시작 메뉴 · «설치된 앱») 회귀는 지난 회차 기준 그대로 다시 돌린다.
- **제약**: 공개 설치 파일(GCS 객체)은 팀장 OK 전에 바꾸지 않는다(«배포 직전 한 줄»). 웹 호스팅 · 함수는 손대지 않는다. 앱 화면 코드는 바꾸지 않는다.

## 추가 수정 5 — 진행 화면 · 묻는 창 · 제거 첫 화면 그림 · 2단계 샘플(10/28 Bumm님, 팀장 전달 — 지시 자체가 승인)

- **문제(e58b65c · cbfde85 실측)**: 두 번 눌러 «모든 사용자»로 덮어쓰면 진행 화면에 7초쯤 막대만 있다가 상자가 갑자기 생기고, 막대가 50% → 5% → 80%로 뒤로 갔다가
  100%를 못 보이고 완료 화면으로 넘어간다(설치 창만 30fps 녹화, `scripts/verify/installer-screen-record.ps1`). 원인은 막대에 쓰는 쪽이 둘인 것이다 —
  NSIS는 명령 수로, 7z 풀기(Nsis7z)는 제 진행률(0~100%)로 같은 막대(ID 1004)를 덮는다. 상자는 `ShowInstDetails nevershow`(템플릿)라 숨어 있다가 첫 문장에서 보였다.
  «창 전체 깜빡임»은 이 PC에서 창이 앞에 없을 때의 녹화로는 재현되지 않았다(빈 화면 0 · 새 창 · 초점 이동 0). 막대가 뒤로 튀고 상자가 갑자기 생기는 것을 없애고 녹화로 다시 본다.
  앱이 켜져 있으면 알림 «OK을 클릭하면 종료»에서 «취소»를 누르면 설치기가 그대로 끝난다. 이미 깔려 있으면 묻지 않고 지우고 깐다.
- **원하는 결과(팀장 전달)**: 진행 화면 — 상자는 처음부터, 막대는 한 방향 · 고르게 · 100%를 1초 보인 뒤 완료 화면, 상자에는 단계 문장 아래 «설치: …» / «삭제: …» 파일 줄,
  마지막 줄 «설치가 끝났습니다.» / «제거가 끝났습니다.», 깜빡임 0. 앱이 켜져 있으면 «끄고 계속할까요?»(확인 = 끄고 이어서, 취소 = 직전 화면, 안 꺼지면 알리고 다시 시도).
  이미 깔려 있으면(같은 위치 · 다른 범위 모두) «지우고 새로 설치할까요?»(확인 = 예전 판을 «삭제: …» 줄과 함께 지우고 설치, 취소 = 설치하지 않음 · 예전 판 그대로, 앞 판이 남지 않음).
  제거 첫 · 완료 화면 왼쪽 그림 = 설치 완료 화면의 극장 그림, 제거 첫 화면 문장은 쉬운 말로. 2단계 «사진 불러오기» 삭제, 설치판도 카메라를 켜기 전에는 «샘플 포스터 보기».
- **방법**:
  - 막대: 원래 막대 자리에 막대를 하나 더 만들어 ID 1004를 넘기고 원래 막대는 숨긴다(번호는 바꿔 둔다). NSIS는 숨은 원래 막대만 건드리고, Nsis7z는 ID로 찾아 새 막대를 움직인다.
    새 막대의 범위를 Nsis7z의 0~30000이 정한 구간(예: 5~80%)에 오도록 잡고, 나머지 단계는 같은 범위에서 앞으로만 옮긴다(시제품으로 확인).
    막대는 창이 뜰 때(화면 스레드) 숨은 채 만들어 두고 진행 화면이 열리면 그 자리로 옮긴다 — 설치기 · 제거기 같은 코드다.
  - 상자: `ShowInstDetails` · `ShowUninstDetails show`. 진행 글 한 줄(막대 위)은 단계 문장만, 상자에는 단계 문장 · 파일 줄.
    설치 파일은 7z로 한꺼번에 풀리므로 파일마다의 순간은 알 수 없다 — 풀기를 마친 뒤 설치 폴더에 실제로 놓인 파일을 하나씩 확인하며 «설치: …»로 적는다(막대도 그만큼 간다).
    제거는 제거기가 파일을 하나씩 지우며 «삭제: …»로 적는다(템플릿 `customRemoveFiles`). 끝나면 마지막 줄 · 100% · 1초.
  - 묻는 창: 설치기는 «설치» 단추를 누를 때(위치 화면을 떠날 때) 묻는다. 템플릿의 위치 화면은 앞 화면(설치 범위)이 MUI 콜백 자리를 먼저 가져가 손댈 수 없어서,
    템플릿 위치 화면을 끄고(`allowToChangeInstallationDirectory` 끔) 같은 MUI 위치 화면을 `customPageAfterChangeDir`에서 직접 넣는다 — 모양 · 단추 이름 «설치»는 같다.
    (진행 화면 SHOW에서 «뒤로»를 보내는 방법은 시제품에서 설치가 뒤에서 그대로 돌아 버려 쓰지 않는다.) 제거기는 첫 화면에서 «다음»을 누를 때 묻는다.
  - 예전 판: 묻는 창에서 «확인»이면 진행 화면이 열릴 때 템플릿의 «예전 판 조용히 지우기»가 비켜 가게 그 설치의 제거 명령 값을 잠시 다른 이름으로 옮겨 두고,
    설치 첫 단계에서 이 설치기가 그 폴더 파일을 하나씩 지우며 «삭제: …»를 적은 뒤 예전 제거기를 조용히 불러 등록 · 바로가기를 정리한다. 실패하면 값을 되돌리고 멈춘다.
    «나만» 위에 «모든 사용자»: 관리자 권한 설치기가 «나만» 판을 지운다(관리자 권한에서 «나만» 제거기가 실제로 지워지는 것 확인 — 10/28).
    «모든 사용자» 위에 «나만»: «모든 사용자» 판은 관리자 권한이 있어야 지워져 예전 제거기를 관리자 권한으로 부른다(다른 PC에서는 승인 창이 한 번 뜬다).
  - 2단계: 설치판도 «두 단추»(`studioMode`) — 샘플은 화면의 «촬영 구도 예시» 사진(개인 · 단체 중 지금 고른 것)을 설치판 로컬 합성으로 8종에 넣고,
    로딩 화면은 설치판 것(AI 장면 · AI 문구 없음)이다. «사진 불러오기» 단추 · 파일 고르기 · 스타일 · 시험 · 설명서 문장을 같이 걷는다.
- **확인**: 설치(나만 · 모든 사용자 새로 · 덮어쓰기 · 두 번 누르기 흐름) · 제거를 설치 창 녹화로 처음부터 완료 화면까지 남기고, 녹화에서 막대 채움 길이가 줄지 않는지 ·
  진행 화면 첫 장면부터 상자가 있는지 · 되돌아가는 번쩍임이 없는지를 잰다. 묻는 창(켜진 앱 · 이미 설치 — 같은 위치 · 다른 범위, 확인 · 취소 각각)을 원본 해상도로 찍는다.
  설치판 2단계 · 샘플 흐름 4개 크기 전/후, 배치 528개, 앱 흐름 회귀. 웹 라이브의 «샘플 포스터 보기»는 보기만 한다(웹 코드는 바꾸지 않는다).

# AI 지시문 동결(장르 × 혼자/단체 16칸)과 출시 준비 — 안전 차단 창 · 독립 리뷰 · 실제 생성 3건 · 격리 리허설

## 문제

- 10/24~25 A/B 시험(실제 생성 227회)에서 지금 라이브 지시문(v1)보다 Bumm님 눈에 나은 판이 장르 · 혼자/단체마다 달랐다.
  칸마다 다른 판을 쓰려면 «어느 칸이 어느 판인가»를 코드 한 곳에 고정하고, 틀린 판이 불리거나 조용히 기본값으로 떨어지는 것을 막아야 한다.
- 안전 차단(moderation_blocked) 창은 «AI 안전 기준에 걸렸어요»라 아이에게 탓하는 말로 읽히고, 같은 입력으로 다시 보내는 것을 막지 않았다.
- 11/14 행사 전 마지막 묶음이라, 배포 전에 다른 눈의 리뷰 · 실제 생성 · 되돌리기 연습이 필요하다.

## 원하는 결과

- 16칸이 Bumm님 확정표대로 판을 쓰고(`PROMPT_VARIANT_BY_CELL`), 칸 하나 · 글자 하나만 바뀌어도 시험이 빨간불이다.
- 안전 차단 때 아이는 «내용을 바꾸거나 다시 찍어 볼까요 ?»를 보고, 사진 · 입력을 바꿔야만 다시 보낼 수 있다.
- Go/No-Go 보고에 독립 리뷰 · 실제 생성 3건(최대 $0.15) · 격리 리허설 · 전체 시험 결과가 근거와 함께 있다. 배포는 승인 뒤.

## 영향받는 사용자·시스템

- 행사 참가 아동 · 교사(포스터 그림의 지시문, 안전 차단 창 문구) — functions와 hosting 둘 다 바뀐다.
- OpenAI 비용: 장당 실측 $0.049~0.050(지시문 길이에 따라 텍스트 토큰만 다르다).

## 제약

- 동결 지시문 글자를 바꾸지 않는다. 옛 후보(v1plus3 등)는 git과 승인 자료에서 추적 가능하게 둔다.
- 8종 디자인 · 촬영 · 4×6 인쇄 · 한글 합성 · 개인정보(이름 · 단체명 · 출연진은 서버로 안 감) · 비용 한도를 유지한다.
- 안전 차단: 같은 요청을 되풀이하는 단추 · 지시문 자동 변경 · 안전 기준 우회 금지.
- 품질 한계는 운영자용 문서에만 — 설명서 · 화면 문구에 넣지 않는다.
- 프로덕션 배포 · push · 샘플 모드 변경 · 승인 작업 덮어쓰기 · 프로덕션에서 되돌리기 연습 · 새 클라우드 자원 만들기는 승인 대상이 아니다.

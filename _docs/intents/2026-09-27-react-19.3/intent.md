# React 19.2.8 → 19.3.0 (react · react-dom · 두 타입 패키지만)

## 문제

전 앱 React를 최신 19.3.0으로 맞추라는 대표 지시(팀장 전달, 2026-09-27). 이 저장소는
`react`·`react-dom` 19.2.8, `@types/react` 19.2.18, `@types/react-dom` 19.2.7이다.

## 원하는 결과

- 네 패키지가 19.3.0이고 lockfile이 그것으로 고정돼 있다. 트리에 React 사본이 하나뿐이다.
- 린트·타입·단위 테스트(루트·functions)·빌드·폰트 검사·도구 자기검사가 전부 통과하고,
  **새로 생긴 경고가 0건**이다(생기면 원인을 고친다 — 우회 금지).
- **화면과 포스터가 올리기 전과 같다** — 같은 조건으로 전/후를 떠서 대조한다:
  스냅샷(computed style·기하·보이지 않는 속성) 4조합 불일치 0건,
  포스터 픽셀 지문 불일치 0건.
- CI 잡별 통과 → 자동 배포 → 라이브에서 새 번들이 19.3.0이고 화면이 뜨는 것을 직접 확인.

## 영향받는 사용자·시스템

- 실사용자: 부스 노트북에서 여는 모든 화면. 동작이 달라지면 안 된다.
- 이 저장소의 프론트엔드만. `functions/`는 React를 쓰지 않아 영향이 없다.
  Vite·TypeScript·`@vitejs/plugin-react`·테스트 라이브러리는 **건드리지 않는다**(한 번에 한 변화).

## 제약

- 🔴 **아이가 인쇄해 가는 포스터가 1픽셀도 달라지면 안 된다.** 픽셀 지문이 하나라도 다르면 배포하지 않는다.
- 하나라도 빨갛거나 동작이 달라지면 **배포하지 않고 멈추고 보고**한다(팀장 조건).
- 검증 중 라이브 `/generate`를 부르지 않는다 — 도구가 응답을 가로채는 것을 확인했다(비용 0).
- 라이브 확인은 세션 자신의 브라우저(헤드리스 크롬)로 한다. 대표님 크롬을 쓰지 않는다.
- 되돌릴 지점(프리즈 태그)을 먼저 찍고, **실제로 되돌려 태그와 차이 0건인지** 확인한다.

## 미결 질문

- 없음. 범위·순서·배포 조건이 지시에 명시돼 있다.

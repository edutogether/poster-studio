# 확정 디자인과 기존 촬영·생성·출력 기능 통합

## 문제

Bumm님이 확정한 화면을 독립 로컬 시안으로만 구현했다. 실제 기능이 기존 React 운영 코드에 남아 있어, 시안 자체를 배포하면 기존 서비스 기능이 사라진다. Bumm님의 배포 요청은 확정한 디자인과 기존 기능을 함께 제공하는 것으로 해석하며, 별도 기능 없는 시안 배포로 대체하지 않는다.

## 원하는 결과

영화 정보 → 실제 카메라 촬영 → 기존 AI 요청과 포스터 네 종류 생성 → 선택·PNG 저장·인쇄까지 하나의 운영 앱에서 동작한다. 확정된 첫 화면 디자인·이름 태그·영화 분류·개인정보처리방침을 유지한다. 실패 안내·다시 촬영·재생성 제한·기본 버전 대안도 유지한다.

## 영향받는 사용자·시스템

- Poster Studio 행사 참가자와 부스 운영 교사.
- 이 저장소의 React 화면·정적 자산·개인정보처리방침·화면 테스트만 통합 대상으로 한다.
- 다른 앱, 다른 작업자의 가지와 세션 설정은 건드리지 않는다.

## 제약

- 포스터 조판 소스·1200×1800 출력·4×6 인쇄 규격은 유지한다. 같은 사진·같은 메타데이터의 결과가 달라지면 안 된다.
- 이름·단체명·출연진 서버 전송 금지, 기존 FormData 허용 항목·한도·타임아웃 유지.
- 실제 과금 API·운영 Firestore·실제 프린터를 검사에 사용하지 않는다. 외부 통신을 차단한 가짜 응답과 카메라로 검증한다.
- 로컬 시안의 가짜 사진·생성 완료·인쇄 안내를 운영 기능으로 오인하게 남기지 않는다.
- 기존 출력 생성 로직의 기본값은 변경하지 않는다. UI 티켓의 예시와 실제 사용자 입력을 구분한다.
- 별도 배포는 기존 CI 경로를 사용하고 main/master에 직접 푸시하지 않는다.

## 미결 질문

제품 범위는 새 디자인과 기존 실제 기능의 통합으로 진행한다. 작업 중 기술적 통합만으로 충족할 수 없는 새로운 정책·출력 규격 결정이 필요해지면 해당 부분만 Bumm님께 확인한다. 기존 기능 유지에 대한 확인을 반복하지 않는다.

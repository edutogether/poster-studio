# Poster Studio 원화 수정본 v8

Bumm님이 제공한 `같이교육 Logo CL(V).png`의 원본을 이 폴더 `logo-reference.png`로 보존했다. 글자 부분을 제외한 상단 심벌을 자르고 흰 배경을 투명화해 `brand-symbol.png`로 저장했다. 도형·색을 다시 그리지 않았다. 제품인 슬레이트·앞치마·스카프 라벨에는 이 원본 심벌 PNG를 작게 합성했다. Bumm님의 원본 자르기·투명화·직접 사용 지시에 따른 처리다.

## 장면 변경

- 1: 붙인 간판을 없애고 꽃밭·정원·분수 배치를 로고 형태로 만든 물감 풍경화.
- 2: 깃발 로고를 없애고 항구·방파제·정원·분수에 로고 형태를 녹인 색연필 풍경화.
- 3: 슬레이트의 심벌은 원본을 36px 폭으로 작게 배치.
- 4: 아이들과 강아지가 로고 형태의 불꽃놀이를 구경하는 크레파스 그림.
- 5·6: 승인된 v7 파일 그대로 유지.
- 7: 악보의 오선지·음표 방향을 종이 평면에 맞춰 수정.
- 8: 종이를 없애고 양손으로 헤드폰 양쪽을 감싸는 가수의 녹음 자세.
- 9: 일반 무대용 마이크에서 검은 휴대용 현장 녹음 마이크로 변경.
- 10·11: 원본 심벌을 앞치마와 작은 봉제 라벨에 배치. AI가 변형한 로고는 제거.
- 12: Bumm님 보류 지시대로 v7 파일 그대로 유지.

원화 장면 수정에는 내장 이미지 생성 도구를 사용했다. 원본 로고 자르기·투명화·제품 합성에는 `scripts/media/original-brand-symbol.mjs`를 사용했다. 전체 생성기는 `scripts/media/build-robot-logo-v6.mjs`이며 최신 대상은 v8이다. 5·6·12번 보존 파일은 `preserved/`에 따로 둔다.

## 상태와 확인

샘플 페이지와 ZIP에 v8 원화를 반영했다. 3초 동영상은 여전히 미제작이며 실제 앱 영상 교체는 하지 않았다. 동영상의 모양·동작 지시서는 변경된 원화에 맞춰 갱신했다.

- 타입 검사·빌드 종료 코드 0.
- 헤드리스 3화면 폭 × 설명 접기/펼치기 6조건, 카드 72건 겹침·가로 넘침 0건.
- 5·6·12번 PNG의 v7/v8 SHA-256 동일 확인.
- 실제 API·카메라·인쇄·배포·커밋·푸시 없음.

# 촬영 안내 영상 구성안

상태: 2026-10-01 Bumm님 결정으로 개인 모드는 기존 여성 안내 사진, 단체 모드는 네 명이 모여 웃는 별도 예시 사진을 사용한다. 개인·단체 영상은 나중에 Bumm님과 Higgsfield에서 제작한다. 현재 영상 제작·플러그인 연결은 진행하지 않는다.

단체 사진 `public/studio/camera-group.webp`는 내장 이미지 생성 도구로 만든 가상의 인물 사진이다(1448×1086, 190,414바이트). 실제 참가자 사진이 아니다. 제작 지시: 밝은 교실 영화 동아리 공간에서 한국인 청소년 네 명이 서로 얼굴을 가리지 않고 함께 웃는 자연스러운 촬영 구도 예시, 글자·로고 없음. PNG 결과를 같은 해상도의 WebP 품질 88로 변환했다. 단체 모드에서는 전체 이미지가 보이도록 표시하며 실제 촬영이나 AI 생성 입력으로 사용하지 않는다.

## 목적

두 번째 화면에 도착한 참가자가 짧은 시범을 보고 자리와 표정을 잡는다. 설명을 읽거나 소리를 들어야만 이해되는 구성을 피한다. 개인·단체 모드에 맞는 영상 한 편을 10초 이내로 한 번 보여준다.

## 개인용 — 총 9초

| 시간 | 화면 |
|---|---|
| 0.0–2.0초 | 기존 안내 이미지와 비슷한 밝은 공간. 인물이 화면 옆에서 들어와 카메라 앞에 앉는다. |
| 2.0–5.0초 | 화면을 보며 의자와 고개 위치를 조금 맞추고, 얼굴·어깨가 프레임 안에 들어온다. |
| 5.0–8.0초 | 편하게 웃고 포즈를 유지한다. 큰 숫자 3 → 2 → 1을 1초씩 표시한다. |
| 8.0–9.0초 | 짧은 셔터 표시와 정지 화면으로 마무리한다. 실제 사진 촬영은 하지 않는다. |

## 단체용 — 총 9초

| 시간 | 화면 |
|---|---|
| 0.0–2.0초 | 먼저 선 한 사람이 양옆을 향해 손짓한다. 자막: “얘들아, 같이 찍자!” |
| 2.0–5.0초 | 친구 2~3명이 옆으로 모여 선다. 서로의 얼굴을 가리지 않도록 자리를 맞춘다. |
| 5.0–8.0초 | 모두 카메라를 보며 웃거나 손으로 작은 포즈를 한다. 3 → 2 → 1. |
| 8.0–9.0초 | 개인 영상과 동일한 셔터 표시와 단체 정지 화면으로 마무리한다. |

## 영상이 준비되면 연결할 재생 동작

- 참가자의 첫 촬영 화면 진입에 현재 개인/단체 모드의 영상을 한 번 재생한다. 다시 찍기·정보 수정 왕복 때 자동 반복하지 않는다.
- 개인/단체 모드를 바꿨다면 해당 모드의 영상을 한 번 보여준다. “다음 주인공”을 누르면 새 참가자 기준으로 초기화한다.
- 소리 없이도 이해되도록 자막·동작으로 구성하고, 자동 재생은 음소거·인라인 재생을 사용한다. 재생 정책에 막히면 재생 버튼을 표시한다.
- 다시 보기·건너뛰기를 제공한다. 움직임 줄이기 설정에서는 정지 이미지와 수동 재생을 기본으로 한다.
- 카메라 켜기 또는 촬영 요청 시 안내 재생을 즉시 중단한다. 안내 영상의 카운트다운과 실제 촬영 카운트다운을 동시에 표시하지 않는다.
- 안내 전용 영상은 실제 촬영 사진·AI 생성 입력으로 사용하지 않는다. 실제 웹캠 스트림과 별도 요소로 분리한다.
- 개인/단체 각 파일의 길이, 첫 진입 한 번 재생, 재입장·모드 전환·초기화, 재생 실패, 실제 카메라 전환을 외부 API 호출 없이 검증한다.

위 시간표는 추후 Higgsfield 제작을 위한 구성안이다. 현재 사진 안내를 영상 구현 완료로 기록하지 않는다.

# Poster Studio 로딩 12세트 확정본

Bumm님 승인: 2026-10-01. samples.html을 열면 확정한 그림·문구·영상 프롬프트를 확인할 수 있다. 캐시 폴더와 서버 없이 열리는 보관본이다.

- assets/01.png~12.png: 영상 제작 시작 원화
- assets/01-영상-프롬프트.txt~12-영상-프롬프트.txt: 각 3초 연속 동작 지시서
- assets/sets.json: 번호별 제목·상식·출처·동작 대응표
- 영상-제작자료.zip: 한 번에 옮길 제작 자료
- 현재 실제 앱은 확정 원화를 사용한다. 새 동영상 12편은 아직 제작되지 않았다. 영상 제작 시 역재생·정지 프레임 늘리기 없이 진행하고 원화 번호와 같은 세트에 연결한다.
- 실제 앱 데이터는 src/studio/waitingSets.ts, 그림은 public/studio/waiting-approved-v1/. 문구·그림을 따로 섞지 않고 세트 단위로 무작위 재생한다.
- 보관본은 승인 원화와 최신 요청 문구를 담는다. 문구 수정 이력은 Git으로 보존한다.

미리보기 재실행: 저장소 루트에서 `node scripts/media/wait-preview-server.mjs`. `http://127.0.0.1:5523/samples.html`은 확정 자료, `/`는 실제 로딩 컴포넌트의 무작위 넘김을 보여 준다. API 연결은 없다.

2026-10-01 후속 요청: 실제 로딩에서 한 줄로 읽히도록 설명 12개를 줄이고 60초 지연 문구를 제거했다. 원화·제목·상식의 주제·영상 프롬프트는 동일하다.

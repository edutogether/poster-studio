# 키프레임으로 다시 만들기 — 01·02·05·09·12 (2026-10-08 Bumm님 지시, 팀장 전달)

## 원칙(Bumm님 말씀 그대로)

«판단해서 적절하게, 한 방에 완벽하게 나오는 게 비용이 제일 싸다. 필요하면 원화부터 다시 그리고, 필요한 만큼 여러 장 그리고, 프롬프트를 제대로 해서 그린다. 동작이 바뀔 때마다 제대로 된 원화를 여러 장 뽑아 두고, 그걸 다 첨부해서 제대로 만든다. 새로 만드는 게 필요하면 굳이 네 선(후보정)에서 처리하려고 하지 마.»

## 만드는 방식

- 동작이 바뀌는 지점마다 키프레임 원화를 먼저 만든다. 승인 원화와 같은 그림체·캐릭터·구도·카메라.
  - 승인 원화를 만든 같은 이미지 도구(ChatGPT 이미지 — Bumm님 계정, 세션 브라우저가 아니라 Bumm님 크롬)를 쓰고 승인 원화를 참조로 넣는다. OpenAI 이미지 API는 쓰지 않는다(Bumm님 기각).
  - 승인 원화 그대로인 키프레임(K1 등)은 그림 도구로 다시 그리지 않고 승인 원화에서 미소선만 지운다(`scripts/media/repaint-visor.py`, 원화 화소 그대로).
  - 얼굴은 주황 눈 두 개만. 입·미소선 없음.
- 영상은 키프레임 사이 구간을 Veo 3.1 Fast로 만들어 잇는다(구간마다 첫·끝 장면 = 앞뒤 키프레임). 8초 = 4초 + 4초 두 구간(Veo는 4·6·8초만 된다). 구간 경계는 같은 키프레임이라 끊기지 않는다.
- 첫·끝 키프레임은 대기 화면에서 반복되도록 같은 자세(05·12는 끝 장면이 달라지는 이야기라 예외 — 2026-10-07 확정과 같다).
- 비용: 편당 8초 $0.64, 다섯 편 $3.20 → 누적 $19.36 → $22.56(상한 $30). 넘을 것 같으면 그 전에 멈추고 검토 페이지 «결정 대기»에 필요 금액과 이유를 적는다.

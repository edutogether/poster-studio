# Poster Studio 디자인 진단과 개선 전략 — 2026-10-02

Bumm님 요청에 따라 현재 8종의 실제 로컬 결과와 조판 코드를 함께 확인했다. 이 문서는 다음 디자인 작업의 기준이다. 여기서 제안한 디자인 비교 버튼과 포스터 재설계는 아직 구현하지 않았다.

## 이번에 반영한 수정

- 상단 표기는 기존 고급형 슬레이트 자산과 Poster Studio이며 Studio만 빨간색이다.
- 기본 이름을 김인키로 통일했다. 준비 화면은 김인키를 표시하지만 getMeta는 인키를 사용하던 불일치가 원인이었다. 성을 제거하는 로직은 없다.
- 입력을 비웠을 때 김인키, 김태범을 입력했을 때 김태범 전체가 8종 캔버스의 주연·감독 문구로 전달되는 것을 실제 브라우저에서 확인했다.

## 버튼 두 자리

현재 왼쪽 rotate-ccw 버튼은 onNewPerson을 호출한다. 카메라 정지, 사진 URL 해제, 입력·포스터 초기화, 첫 단계 이동을 수행한다. 디자인을 되돌리거나 새 그림을 생성하는 버튼이 아니다. 오른쪽 maximize는 선택 포스터를 모달에서 크게 연다.

추천 조합은 왼쪽 **디자인 비교**, 오른쪽 **크게 보기**다. 비교는 사용자가 고른 두 디자인을 같은 크기로 나란히 보는 동작이어야 한다. 큰 포스터 주변에는 결과를 살피는 동작을 둔다. 처음부터 시작은 인쇄 이후에도 찾기 쉬운 별도 위치에 **처음부터 시작**이라는 글자와 홈 아이콘을 함께 둔다. 문구 수정은 다음 우선순위로, 그림을 유지한 채 제목·이름만 다시 조판하는 기능이 적합하다.

## 근본 원인

### 1. 장면보다 프레임이 조판을 결정한다

모든 틀이 같은 완성 원화를 coverDraw로 잘라 넣고 세로 정렬값 0.35를 공유한다. 인물이나 중요한 소품의 위치를 모르므로 틀 모양에 맞게 잘라내면서 주인공·배경 관계를 잃는다. 1024×1536 원화를 에디토리얼의 1040×962 칸에 넣으면 원화 높이의 약 61.7%만 보인다. 이 비율은 현재 샘플 기준이고 다른 원화의 인물 위치는 별도 확인해야 한다.

해결: 주인공과 중요한 장면을 표시한 보호 영역을 기준으로 틀별 크롭을 정한다. 허용 크롭으로 인물을 지킬 수 없으면 이미지 칸의 비율을 바꾼다. 8종의 차이는 인물을 없애거나 가르는 방식으로 만들지 않는다. 긴 단계에서는 생성 구도에 제목 여백과 인물 위치를 함께 지정하고, 현재 원화로 하는 작업에서는 크롭·배치부터 해결한다.

### 2. 제목과 이미지의 관계가 약하다

대부분의 제목은 굵은 고딕 또는 명조를 고정 위치에 넣은 형태다. 두 줄 분할도 글자 폭의 균형에 의존한다. 단어 의미·장면의 시선·글자의 형태를 함께 결정하지 않으므로 제목이 별도 UI 텍스트처럼 보인다. 겹침이 없어도 완성된 제목 디자인이라는 뜻은 아니다.

해결: 각 틀의 대표 제목을 먼저 디자인한다. 짧은 제목·보통 제목·긴 제목별 줄바꿈과 크기를 별도로 설계하고 실제 글자 모양의 여백을 기준으로 조정한다. 별을 찾는 아이는 별을 찾는 / 아이처럼 의미 단위로 분할한다. 외곽선·그림자는 장면에서 필요한 정도만 사용하며 장식으로 늘리지 않는다.

### 3. 그림과 색면이 따로 움직인다

컬러 블록의 노랑·파랑과 타이포그래피의 주황은 고정값이다. 현재 황금빛 숲 그림에서는 색면 자체가 시선을 강하게 끌어 그림과 제목의 관계를 약하게 만든다. 폴라로이드의 빨강도 작품의 분위기보다 프레임을 먼저 보게 한다.

해결: 원화의 어두운 기본색·밝은 중간색·작은 강조색을 추출해 틀별 역할을 배정한다. 현재 원화라면 숲의 짙은 녹색, 종이색, 빛의 금색이 출발점이다. 강한 색면은 장면과 연결될 때 사용하고 앱 UI의 빨강을 모든 작품의 포스터 색으로 강제하지 않는다.

### 4. 장식이 이야기보다 앞선다

아치·필름 구멍·기울어진 사진·세 폭 분할은 형태 차이를 만들지만 그 장식이 왜 이 작품에 필요한지는 약하다. 특히 이미 원화 안에 문이 있는 장면을 다시 아치로 감싸거나 인물 주변을 세 폭으로 자르면 장면이 답답해질 수 있다.

해결: 틀마다 하나의 조형 원리만 강하게 쓴다. 실제 인화물에서 의미가 있는 프레임 두께·종이 여백을 정하고, 구멍·회전·분할의 크기를 주인공보다 튀지 않도록 조정한다.

### 5. 정보의 위치는 반복되지만 정보의 무게가 정리되지 않았다

두 로고·홍보 문구·제목·주연·감독·행사명·날짜가 들어가며 여러 틀에서 하단 정보가 비슷한 크기로 멀리 떨어진다. 이는 정보를 한 묶음으로 읽기 어렵게 하고 바닥의 빈 공간을 불필요하게 크게 느끼게 한다.

해결: 주인공 → 제목 → 홍보 문구 → 크레딧·행사 정보의 우선순위를 정한다. 상단 두 로고의 지정 위치와 원본 비율을 지키면서 작품 제목과 경쟁하지 않는 무게로 정리한다. 행사명·날짜·장소는 하나의 정렬 축에 묶고, 간격은 실제 글자 경계와 인화 크기를 기준으로 잡는다. 글씨를 더 추가해 여백을 채우지 않는다.

### 6. 기술 검증과 시각 품질 검증이 분리되지 않았다

기존 128검사는 작동·글자 겹침·캔버스 경계를 검증한다. 디자인의 세련됨, 주인공의 보존, 색의 조화까지 검증한 것은 아니다. 실제 캔버스 단위검사의 명조는 오프라인 환경에서 대체 글꼴로 그려질 수 있다. 현재 브라우저 검증도 외부 통신을 막으므로 외부 명조와 실제 인화 품질을 확정하는 근거로 쓰면 안 된다.

해결: 기술 검사는 계속 유지하고, 시각 검토는 별도로 한다. 최종 폰트를 로드한 전체 크기 PNG, 축소 카드, 실제 4×6 크기의 결과를 각각 확인한다. 검토 기준은 주인공 보존, 제목 읽기, 그림·글자의 관계, 색 조화, 정보 정렬, 인화 안전 여백이다.

## 8종별 작업 방향

| 디자인 | 현재 약점 | 개선 방향 |
|---|---|---|
| 시네마 | 하단 큰 제목과 어두운 페이드에 의존 | 인물·빛·제목을 한 흐름으로 배치하고 페이드 깊이를 장면별로 조정 |
| 에디토리얼 | 세로 원화를 넓은 칸에 잘라 인물과 여정을 잃음 | 이미지 칸을 인물에 맞춰 세로로 잡고 제목·그림·정보의 정렬 축 통일 |
| 컬러 블록 | 고정 원색이 그림과 충돌 | 원화에서 색을 가져오고 한 가지 큰 색면으로 제목 강조 |
| 아치 프레임 | 원화의 문과 외부 아치가 중복 | 창의 곡률·여백을 정교하게 잡고 장면과 프레임이 한 형태로 보이게 구성 |
| 필름스트립 | 구멍이 크게 드러나 기성 프레임 느낌 | 구멍의 시각적 무게를 줄이고 제목·정보를 필름 규칙과 정렬 |
| 폴라로이드 | 기울기·빨강 배경·명조가 각각 작동 | 종이 여백, 자연스러운 그림자, 그림에서 가져온 배경색을 함께 설계 |
| 타이포그래피 | 큰 고딕 제목을 위에 붙인 정도 | 제목의 줄 구조·공백을 포스터 전체의 조형 요소로 사용하고 이미지 크롭과 연동 |
| 트립틱 | 선이 장면과 인물을 가를 수 있음 | 인물을 보존하며 장면의 흐름을 세 폭으로 나누고 제목·하단 정보 정렬을 연결 |

## 작업 순서와 완료 기준

1. 현재 원화 한 장으로 시네마·에디토리얼·타이포그래피의 대표안을 각각 완성한다. 장면 중심, 종이 조판 중심, 제목 중심의 완성 기준을 먼저 세운다.
2. 세 안에서 정한 제목·색·정보 정렬 기준으로 다른 다섯 디자인을 발전시킨다. 종류 수를 늘리기 위한 장식 변주는 제외한다.
3. 짧은 제목, 별을 찾는 아이, 긴 제목, 단독 주연, 단체 출연진으로 검토한다. 기존 장르별 원화도 사용해 얼굴과 주요 장면을 잘라내지 않는지 확인한다.
4. 1200×1800 원본·선택 카드·4×6 인화 크기에서 각각 검토한다. 현재 1200×1800은 4×6인치에서 300ppi에 해당한다. 종이 출력은 실제 프린터 확인 전까지 완료로 보고하지 않는다.
5. 대표안의 주인공과 제목이 먼저 읽히고, 제목 크기·색·프레임이 원화와 한 작품으로 느껴질 때 8종 전체에 반영한다. 동작 검사 통과와 시각 검토 결과는 구분해 기록한다.

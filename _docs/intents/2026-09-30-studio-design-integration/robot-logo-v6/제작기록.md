# Poster Studio 로고 원화 12세트

2026-10-01 Bumm님 지시: 기존 별 그림을 제공한 같이교육 로고로 교체하고, 빈 8장까지 완성하며, 반복·역재생처럼 보이는 동작을 개선한다.

## 완료된 범위

- 내장 이미지 생성 도구로 3개의 2×2 원화 시트를 제작했다. 원화 12장은 물감·색연필·슬레이트·크레파스 포스터·폴리·찰흙·피아노·대사 녹음·현장음 녹음·점프 준비·스카프·스케치 선택이다.
- 빨간 ㄱ·초록 ㅇ·파란 ㅇ·주황 ㄱ과 연결된 웃음 곡선으로 로고를 맞췄다. 9~12번 최초 결과의 주황 ㄱ 누락·연결 분리를 두 차례 수정했다. 원본을 픽셀 그대로 붙인 것이 아니라 장면 소재에 맞춰 재생성한 표현이다.
- 물감은 붓 자국, 색연필은 선 결, 슬레이트는 인쇄, 포스터는 크레파스, 입체물은 찰흙, 스카프는 자수로 표현했다.
- `image-prompts.json`에 실제 원화 생성·수정 프롬프트, `sets.json`에 12개 문구·상식·영상 동작을 보존했다.
- `scripts/media/build-robot-logo-v6.mjs`가 개별 PNG·WebP와 한글 영상 프롬프트를 만들고 로컬 샘플 페이지를 갱신한다. PNG는 704×704 캔버스에 원화 크기를 유지해 여백을 더한 것으로, 원본보다 해상도를 늘린 그림이 아니다.
- 로컬 `http://127.0.0.1:5523/samples.html`에 원화 12장과 다운로드를 반영했다. 실제 앱 소스·기존 영상은 바꾸지 않았다.

## 아직 완료하지 못한 범위

자연스러운 연속 동영상 12편과 실제 앱 적용은 미완료다. 연결된 도구에 동영상 생성 기능이 없다. Bumm님에게 Higgsfield 직접 제작용 파일 전달 또는 연결 확인 중 어느 경로로 이어갈지 질문했으며, 현재 답변 대기다.

기존 `build-robot-v5.mjs`는 6장의 키프레임을 `[0,0,1,2,3,4,5,5,4,3,2,1,0,0,0,0]` 순서로 배치했다. 멈춤과 역재생처럼 보인다는 지적에 해당하는 구조다. 새 원화를 같은 방식으로 영상처럼 포장하지 않았다. 각 영상 지시서는 6초 동안 한 방향으로 행동이 진행되도록 작성했다.

완성된 영상이 들어오면 로고 유지·눈길·손과 소품·바닥 접지·역재생 없는 연속 동작을 확인한 뒤 12세트 데이터와 함께 앱에 적용한다. 이번 원화만으로 애니메이션까지 완성됐다고 보고하지 않는다.

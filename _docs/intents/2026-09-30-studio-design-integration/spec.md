# 구현·검증 규격

- 확정한 영화관·티켓·여덟 장르 화면을 `StudioView`로 표시한다. 이름은 빈 입력과 예시를 구분하고 출연진 구분자는 태그로 표현한다. 한글 조합 중에는 태그를 만들지 않는다.
- 카메라 단계는 실제 `getUserMedia`와 기존 JPEG 캡처를 사용한다. 촬영 완료·단계 이탈·언마운트 때 스트림을 끄고, 권한 응답이 뒤늦게 도착해도 이탈한 화면에서 카메라를 켜지 않는다.
- AI 요청은 기존 FormData 다섯 필드만 전송한다. 중복 요청 차단, 사진당 2회 제한, 150초 중단, 실패 시 기본 버전을 유지한다.
- 결과 단계는 기존 `buildPosters`의 네 캔버스를 사용한다. 선택한 캔버스 그대로 PNG 다운로드와 4×6 인쇄로 이어진다. 화면용 시안 이미지를 결과 포스터로 쓰지 않는다.
- 입력 초기화는 사진을 남긴다. 다음 주인공은 입력·사진·결과를 모두 비운다. 포스터 출력 함수·메타데이터 기본값은 그대로 둔다.
- 본문 링크는 확정한 개인정보처리방침으로 연결한다. 방침 문의 링크는 같이교육 인스타그램이고 파란색 밑줄로 표시한다.
- 전체 테스트, 타입·린트·빌드·폰트·검증 도구 자기검사, 이전/이후 20장 픽셀 동일성, 1920·1366·1280·390 화면 검사가 통과해야 원격 반영한다.
- 실제 OpenAI·Firestore·카메라·프린터 없이 가짜 응답과 캔버스 스트림으로 확인한다. 브라우저 검증은 외부 네트워크 차단을 함께 건다.

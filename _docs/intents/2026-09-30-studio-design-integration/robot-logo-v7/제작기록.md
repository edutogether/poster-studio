# Poster Studio 원화 수정본 v7

Bumm님이 지적한 12개 장면을 내장 이미지 생성 도구로 수정했다. 생성·보정 프롬프트는 `image-prompts.json`, 실제 12세트 연결과 영상 지시는 `sets.json`에 기록했다.

1. 이젤은 물감으로 그린 마을·풀밭·꽃 풍경화. 로고는 풍경 속 작은 간판에 넣었다.
2. 색연필로 바닷마을 전체를 그리는 장면. 옆에서 기울인 화판을 보도록 바꿔 로봇에게도 그림이 똑바로 보인다.
3. 슬레이트는 흰 구획선을 추가하고 로고를 작고 각이 정돈된 형태로 바꿨다.
4. 아이들이 상상 세계를 탐험하는 크레파스 포스터로 변경했다.
5. 모래판 앞 로고를 오른쪽 아래 작은 제작자 표식으로 줄였다.
6. 카메라의 로고를 제거했다. 찰흙 작품은 유지했다.
7. 피아노 악보를 오선지와 음표로 바꿨다.
8. 손에 든 종이도 오선지와 음표로 바꿨다.
9. 손에 든 장비를 로고 없는 검은 마이크로 바꿨다.
10. 앞치마를 단정한 면 소재와 작은 자수 로고로 수정했다. 재생성 중 발생한 빨간 T·주황 선 분리를 추가 수정했다.
11. 스카프 끝에 작은 직조 라벨과 손바느질 테두리를 넣었다.
12. 네 장을 바다·정원·아이들과 강아지·우주 그림으로 각각 다르게 만들었다.

`scripts/media/build-robot-logo-v6.mjs`의 최신 생성 대상은 v7이다. 개별 704×704 PNG/WebP, 영상 프롬프트, 샘플 페이지를 만든다. 전체 다운로드는 로컬 `.cache/wait-preview/robot-logo-v7.zip`이다. 소스 시트 원본은 이 폴더에 보존한다.

샘플 페이지 `http://127.0.0.1:5523/samples.html`만 수정했다. 실제 앱의 영상 교체는 수행하지 않았다. 연속 동영상은 여전히 미제작이며 정지 원화를 애니메이션 완료로 표시하지 않는다.

## 2026-10-01 — Poster Studio 샘플 겹침 수정·영상 길이 정정

Bumm님 지적대로 정지 원화는 요청한 3초 동영상의 완성물이 아니다. 연결 도구를 다시 확인했으나 연속 영상 생성 도구는 없다. 영상 12편은 여전히 미제작이며 실제 앱 교체도 미완료다. 기존 6초 영상 지시서·세트 메타데이터·다운로드를 3초로 바로잡았다.

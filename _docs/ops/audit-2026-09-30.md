## 범위와 결론

공통 인계 문서 §4의 분기 감사와 Bumm님의 새 디자인 배포 요청을 함께 처리했다. 독립 Codex 검토자 두 명이 위험·품질 항목을 나눠 확인했다. Claude Opus·Sonnet 호출 도구가 없어 원문 지정 모델 조합을 수행했다고 주장하지 않는다. 최초 감사 후 Bumm님의 배포 지시에 따라 발견 사항을 수정하고 실제 기능을 새 화면에 통합했다.

확정된 디자인에서 실제 촬영·AI 요청·네 가지 조판·PNG 저장·인쇄 핸들러가 연결된다. 정적 디자인 시안은 배포 대상이 아니다. 자동 검사에서 남은 실패는 없으며, 실제 서비스 전체에 오류가 없거나 현장·정책 확인까지 끝났다는 뜻은 아니다.

## 재현

수정 전 `dist/`를 별도 경로에 보존한 뒤 새 빌드를 만들고 다음 명령을 실행한다. Windows Chrome 기본 경로가 다르면 `CHROME_PATH`를 지정한다.

```powershell
node scripts/verify/studio-flow.mjs .cache/integration-baseline/dist
node scripts/verify/poster-pixels-compare.mjs .cache/studio-verification/pixels-0.json .cache/studio-verification/pixels-1.json
```

스크립트는 로컬 5530·5531 및 전용 헤드리스 Chrome 9531을 사용하고 종료 때 정리한다. 외부 네트워크를 차단하고 AI 응답·카메라·인쇄를 대체한다. Bumm님의 브라우저와 실제 장치를 사용하지 않는다. 결과 JSON과 화면은 `.cache/studio-verification/`에 남긴다.

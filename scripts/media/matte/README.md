# 대기 영상 누끼 도구

생성 대기 화면의 12세트 영상을 **흰 카드가 아니라 투명하게** 얹기 위한 도구다(2026-10-06 Bumm님 결정 86).
2026-10-05~06에 04번 시험 영상으로 기준을 정했고, 2026-10-07에 로컬 `.cache/tools/`에서 이 폴더로 옮겼다.
옮긴 뒤 같은 입력으로 다시 돌려 단계별로 **화소 차이 0**(가장자리 안정화 192프레임·측정값, AI 투명도), Veo 원본부터 7단계 전체도 돌아가는 것을 확인했다(AI 투명도가 CPU로 장당 약 12초라 한 편 약 45분).

> 유료 생성은 이 도구의 일이 아니다. Veo 원본은 Bumm님 승인을 받아 만든 뒤 여기에 넣는다.
> 영상에서 원화에 없는 얼굴 요소(눈썹·입 등)가 생기면 누끼와 상관없이 탈락이다(`../check-face-elements.py`).

## 한 편 돌리기

```bash
bash scripts/media/matte/run_scene.sh <장면 01~12> <Veo 원본 mp4> <작업 폴더>
```

| 단계 | 도구 | 하는 일 |
|---|---|---|
| 1 | `extract_square.sh` | 1280×720에서 가운데 720 정사각형 → 704 프레임 PNG·확인용 MP4. Veo 맨 아래 한 줄(거의 검정)을 위 줄로 메운다 |
| 2 | `matte_frames.py` | BiRefNet 투명도(색은 그대로). 이미 만든 프레임은 건너뛴다 |
| 3 | `refine_matte.py`·`refine_frames.py` | 트라이맵(경계 ±3화소) → 클로즈드폼 매팅 → 옆 배경 섞임 걷기 → 그림자는 «검정 + 투명도», **진하기 ×1.6**(최대 0.85) |
| 4 | `stabilize_edges.py` | 움직이지 않는 화소 중앙값 + 가장자리 띠 색 가중 시간 평균(±2프레임). 흰 테두리 소품은 소수 화소 추적·고정 직선 |
| 5 | `encode_alpha.sh` | VP9 알파 WebM(24fps·crf 28). 투명도가 빠지면 실패 |
| 6 | `edge_metrics.py` | 소품 가장자리 떨림·종이 띠 두께, 캐릭터 가장자리 깜박임, 넓이·흰 바탕 재합성 차이 → `final.edge-metrics.json` |
| 7 | `../check-face-elements.py` | 원화에 없는 얼굴 요소 검사. 0 통과 · 1 탈락 · 3 사람 확인 |

**얼굴 보정을 다시 한 장면**은 처음부터 돌리지 않고 `rematte_changed.sh <장면> <새 보정 프레임 폴더> <장면 작업 폴더>`로 다시 딴다.
바뀐 프레임만 AI 투명도를 새로 계산하고(같은 입력이면 결과가 화소 차이 0이라 안 바뀐 프레임은 그대로 맞다), 3~6단계는 앞뒤 프레임을
보므로 전부 다시 돈다. 얼굴판 안쪽만 고쳐도 투명도는 바뀌므로(06번 118번 실측 최대 5/255) 옛 투명도를 그대로 쓰지 않는다.

**마지막은 사람 확인이다.** 자동 단계를 통과해도 확인 페이지에서 원본 화소를 4배로(부드럽게 보정하지 않고)
흰·노랑·회색·검정·무늬 바탕에 얹어 본다. Bumm님께 보일 캡처는 영상마다 따로, 원본 해상도로 남긴다.

## 기준값(바꾸려면 Bumm님 결정이 먼저)

| 무엇 | 값 | 근거 |
|---|---|---|
| 그림자 | 검정 + 투명도, 모양·위치는 원화 그대로, 진하기 ×1.6(가장 진한 곳 0.85) | 결정 101 |
| 그림자/그림 가르기 | 밝기 대비 색 기운(HSV 채도) 0.3, 바깥 밝기 120 미만은 그림자 | 결정 102 — 신발빛 비친 접지 그림자를 그림으로 되살리면 밑창 밑에 갈색·회색 띠가 남는다(04번 실측) |
| 지워진 그림 되살리기 | 150화소 이상 덩어리 중 **덩어리 평균** 채도 0.3 이상만 | 화소마다 가르면 잎에 구멍이 났다(09번) |
| 가장자리 | 소품은 소수 화소 추적·고정 직선, 캐릭터 띠는 색이 같은 앞뒤 2프레임끼리만 평균. 반투명 폭 제한은 쓰지 않는다 | 결정 119 — 04번에서 종이 띠 튐 6→0, 바깥 경계 튐 5→0, 캐릭터 큰 변화 23,369→1,152, 넓이 +0.01% |

## 장면 설정 — `scenes.json`

`poster`는 **흰 테두리 소품**(포스터처럼 배경과 색이 같은 종이)이 있는 장면만 채운다. 지금은 04번만 있다.
새 장면에 그런 소품이 있으면 영상을 받은 뒤 04번처럼 잰다: 원화에서 꼭짓점 4개, 로봇·손과 안 겹치는 소품 그림 안쪽(추적 영역),
손가락이 걸친 구간, 가장자리를 재는 줄과 범위. 소품이 없으면 `null` 그대로 — 4단계는 시간 정리만 한다.

## 설치(한 번) — 저장소 밖 격리 폴더

전역 파이썬·PATH·레지스트리를 건드리지 않는다. 지우려면 `.cache/tools`를 통째로 지우면 된다.

```bash
python -m venv .cache/tools/rembg-venv
.cache/tools/rembg-venv/Scripts/python -m pip install --no-cache-dir -r scripts/media/matte/requirements.txt
```

- 모델: BiRefNet-general-epoch_244.onnx(약 928MB, md5 `7a35a0141cbbc80de11d9c9a28f52697` — rembg가 받을 때 대조)를
  `.cache/tools/rembg-models`(환경변수 `U2NET_HOME`)에 받는다. 첫 실행 때 자동으로 받는다.
- 출처·라이선스: rembg 2.0.85(MIT, github.com/danielgatis/rembg), onnxruntime 1.30.0(MIT), BiRefNet(MIT, github.com/ZhengPeng7/BiRefNet).
- ffmpeg·ffprobe가 PATH에 있어야 한다(libvpx-vp9 포함).

# 🎬 InKY AI 영화 포스터 제작소 (v2)

노트북 + 웹캠 + 포토프린터로 운영하는 **제4회 인천어린이청소년영화제** 체험부스 웹앱입니다.
웹캠으로 찍은 사진을 AI가 영화 포스터로 바꾸고, **클래식·임팩트·시네마·포토카드 4가지 버전**을 즉석에서 골라 인쇄합니다.

## v2에서 새로워진 점
- **개인 / 단체 선택** — 단체면 ‘단체명’과 ‘출연진’을 넣으면 크레딧에 자동 반영
- **영화 제목 자동 타이포그래피** — 장르별 폰트·강조색·홍보문구가 자동 적용
- **한 번에 4가지 고퀄 버전** 생성 → 갤러리에서 클릭해 선택
- 영화 크레딧 블록·월계관(공식 초청작 느낌)·필름 그레인 등 ‘진짜 포스터’ 디테일
- 얼굴 보존 강화(input_fidelity), 현장 안정성을 위한 자동 재시도

## 준비물
- 노트북 1대(Chrome 권장) · USB 웹캠(Logitech C920/C922) · 포토프린터(Canon SELPHY CP1500 등)
- 인터넷 연결, OpenAI API 키, Node.js 20 이상

## 설치
\`\`\`bash
npm install
cp .env.example .env      # .env 를 열어 OPENAI_API_KEY 입력 (키는 .env 에만!)
\`\`\`

## 실행
\`\`\`bash
npm start
\`\`\`
브라우저에서 **http://localhost:3000** 접속.

## 운영 순서
1. 카메라 켜기 → 3·2·1 촬영
2. 개인/단체 선택, 이름(또는 단체명·출연진), 영화 제목, 장르 입력
3. AI 포스터 만들기 → 4가지 버전 자동 생성
4. 갤러리에서 마음에 드는 버전 클릭
5. 인쇄하기(또는 PNG 저장)

## 운영 옵션(.env)
- IMAGE_MODEL: 기본 gpt-image-2(최신·얼굴보존 우수). 문제 시 gpt-image-1.5로 한 줄만 교체.
  · 정확한 모델명은 platform.openai.com 모델/요금 페이지에서 확인해 그대로 입력하세요.
- IMAGE_QUALITY: low / medium / high (4x6 인화는 medium 충분, 귀빈용만 high)
- VARIANTS: 한 번에 만드는 AI 그림 장수(1~2). 1이면 4컷, 2면 8컷.

> 비용 감(참고): gpt-image-2 세로 medium 약 $0.04/장. 행사 규모(약 1,000명, 1인 1~2회)면 대략 $20~30 수준.
> 2K·4K는 4x6 인화에 불필요하니 medium 권장.

## 프린터 팁
- SELPHY는 4×6 인화지 기준. 포스터가 2:3 비율이라 4×6에 꽉 맞습니다.
- 인쇄 대화상자에서 여백 없음(Borderless) 선택.
- 행사 전 10장 이상 테스트 출력 권장.
